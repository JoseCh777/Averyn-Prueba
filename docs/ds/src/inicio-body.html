Qué es Horizonte

Horizonte es el design system de Averyn: el conjunto de reglas, piezas y pantallas que hacen que la landing, el acceso y el panel se vean y se comporten como un solo producto. Está pensado para una plataforma de identidad y biometría, donde la claridad y la confianza importan más que la decoración.

Una sola señal

El azul de marca es el único color de acción. El resto es tinta, líneas finas y estados con palabra.

El horizonte que se oscurece

La información va de lo claro a lo oscuro. El fondo cambia cuando el contenido cambia de naturaleza.

Honestidad

Lo que no existe se dice ("Próximamente"). Nada finge datos reales y el color nunca es el único canal.

Mapa del sistema

El sistema se organiza por propósito. Si buscas una pieza reutilizable, está en Componentes; si buscas una pantalla o un flujo, en Patrones o Plantillas; si buscas un valor (color, espacio, token), en Fundamentos.

SistemaFundamentosPrincipios, marca y figura de arcos, color, tipografía, espacio, iconografía y tokens exportables. SistemaComponentesBotones, formularios, fechas, tablas y píldoras de estado, navegación, alertas, toast, modal, drawer y más. SistemaGráficos12 tipos de gráfico con paleta validada, tooltip, teclado, vista en tabla y modelos de datos. AplicaciónPatronesPatrones de página y los propios de Averyn: captura facial y de huella, verificación, OCR, tarjetón electoral, consentimiento. AplicaciónPlantillas y estadosPantallas completas (bitácora, configuración, persona…), estados de carga y vacío, y las páginas de error. Marca y calidadMarca y entregablesIlustración con arcos, favicons e imagen social, correos transaccionales y estilos de impresión. Marca y calidadCalidad y gobernanzaMicrocopy, accesibilidad, versiones y novedades, deuda conocida y cómo usar el sistema en una pantalla nueva.

Cómo compartir el design system

Todo el sistema viaja en un solo archivo HTML: docs/averyn-design-system-horizonte.html. Se abre con doble clic, sin servidor, y se puede enviar por correo o Drive. Necesita internet solo para las fuentes de Google y los iconos.

python docs/ds/src/tokens_export.py   # tokens.json desde tokens.css
python docs/ds/src/emails.py          # correos transaccionales
python docs/ds/src/build.py           # páginas (valida ids y enlaces)
python docs/ds/src/bundle.py          # el HTML único para compartir

Los gráficos, patrones y plantillas son ejemplos de cómo usar el sistema, con datos ficticios: no son una copia fiel del producto final y todavía no existen en el frontend real. El detalle está en la deuda conocida.
