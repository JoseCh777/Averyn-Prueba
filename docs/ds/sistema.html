Estados del sistema

Una página de error que ayuda

Cuando algo no sale como se espera, la pantalla no regaña ni se disculpa de más: dice qué pasó, qué hacer y deja salida. Es la misma firma de Averyn, el horizonte y los arcos, pero con los arcos rotos: la figura "no encaja", igual que la página que se buscaba.

  1. Número decorativo. Space Grotesk 500 enorme, aria-hidden: el encabezado real es el <h1>.
  2. Etiqueta de error. Mono mayúsculas en cian-glow: "Error 404 · Página no encontrada".
  3. Encabezado (h1). Una frase corta y humana: "No encontramos esa página."
  4. Apoyo. Qué pasó y qué revisar, en ≤ 2 líneas de 46 caracteres.
  5. Ruta pedida (404 y 403). Mono en un marco de línea fina; se inserta como texto, nunca como HTML. No aparece en la vista previa.
  6. Acciones. Una primaria y como mucho dos secundarias. Siempre hay una salida.
  7. Figura de arcos rotos. Los arcos se dibujan y después se separan; un aro cian marca el hueco.
Hacer
  • Una frase de causa y una de salida; nunca más.
  • Dar siempre un botón primario (volver, reintentar o ingresar).
  • Mostrar la ruta pedida: ayuda a detectar un error de escritura.
  • Tratar los módulos pendientes como "Próximamente", no como un error.
No hacer
  • Culpar al usuario ("hiciste algo mal") ni disculparse con exceso.
  • Mostrar códigos internos, trazas, IDs de servidor o rutas del sistema de archivos.
  • Humor o ilustraciones juguetonas: es una plataforma de identidad.
  • Inventar tiempos ("vuelve en 5 minutos") que no podemos garantizar.

Ruta anidadaEl servidor puede responder con la 404 en /dashboard/algo/mal: un script inline en el <head> escribe <base href> con la raíz de la app, para que los estilos y las imágenes carguen desde cualquier ruta.

Cómo se construye la figura rota

Es la figura de arcos con tres piezas desplazadas. Para que antes de separarse encajen al píxel, las curvas se parten con el algoritmo de De Casteljau en lugar de dibujarse a ojo.

Antes de separarse
Después (estado final) 
def split(P, t):  # De Casteljau: divide una cúbica en dos que encajan exactamente
    lerp = lambda a, b: (a[0] + (b[0]-a[0])*t, a[1] + (b[1]-a[1])*t)
    p01, p12, p23 = lerp(P[0], P[1]), lerp(P[1], P[2]), lerp(P[2], P[3])
    p012, p123 = lerp(p01, p12), lerp(p12, p23)
    s = lerp(p012, p123)
    return (P[0], p01, p012, s), (s, p123, p23, P[3])

/* Cada pieza que se separa va en un <g class="er-crack"> con su desplazamiento */
.er-crack { animation: er-crack .7s var(--av-ease-out) 1.5s forwards; }
@keyframes er-crack { to { transform: translate(var(--cx), var(--cy)); } }

La animación va en un <g> envolvente y no en el trazo: el trazo ya usa animation para dibujarse y dos clases con animation se pisarían. Desplazamientos: arco medio (+18, +14), arco interior (+22, −8), diagonal inferior (−22, +10).
