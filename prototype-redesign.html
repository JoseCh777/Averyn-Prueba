Identidad digital para procesos institucionales.

Averyn conecta identidad, biometría, OCR e inteligencia artificial en una plataforma multi-tenant segura, trazable y auditable.

Ingresar al sistema Ver capacidades

Capacidades

Un núcleo común, módulos a la carta.

Cada capacidad está conectada a la identidad: desde el enrolamiento biométrico hasta la auditoría de operaciones críticas.

Identidad

Personas con identificadores propios, documentos múltiples y afiliaciones por institución multi-tenant.

Biometría

Enrolamiento y verificación de rostro y huella con liveness, calidad y plantillas protegidas.

OCR documental

Extracción y validación de datos de documento antes de asociarlos a una persona.

Inteligencia artificial

Modelos versionados y trazables para detección facial, liveness y clasificación.

Seguridad

Roles, permisos, cifrado y aislamiento de tenants como dominios de primera clase.

Auditoría

Registro trazable de cada operación crítica: LOGIN, PERSON_CREATED, BIOMETRIC_VERIFIED.

Arquitectura

Monolito modular orientado a dominio.

Core (NestJS + PostgreSQL/Prisma) con servicios independientes de Face, Fingerprint y OCR, todos tras un contrato estable.

Frontend

Next.js · App Shell · Design System con tokens compartidos.

Core API

NestJS · REST /api/v1 · Tenant context · validación de DTO.

PostgreSQL

Prisma ORM · migraciones · integridad referencial multi-tenant.

Servicios

Face (ArcFace), Fingerprint (DigitalPersona) y OCR desacoplados.

Seguridad

Seguridad por diseño, no por capa.

RBAC

Modelo usuario → rol → permiso → recurso con autorización granular.

MFA

Autenticación reforzada para operaciones críticas del dominio.

Auditoría

Cada login, enrolamiento y voto queda registrado con actor, tiempo y resultado.

Equipo

Construido desde la ingeniería.
